# SWF Authentication Integration Guide for AVA1

This document outlines the step-by-step process for integrating the SWF Authentication Microservice into the AVA1 application. 

**Architectural Concept:** 
AVA1 **does not** generate tokens or handle user passwords locally. Instead, AVA1 acts as a proxy/client that delegates authentication (login, register) by calling `SWF-Auth-dev` external APIs via OpenFeign. AVA1 then uses the JWT tokens returned by `SWF-Auth-dev` to authorize subsequent requests.

## Prerequisites
- AVA1 application running (Spring Boot 3.2.x).
- SWF Auth Microservice running and accessible on `http://localhost:8081`.

## Step 1: Add Required Dependencies
Add Feign Client dependencies in `AVA1/pom.xml` to consume the SWF Auth APIs easily.

```xml
<!-- OpenFeign for calling SWF Auth service -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>
```

## Step 2: Configure Properties
Add SWF Auth service routing details in `application.properties` or `application.yml`.

```properties
# SWF Auth service URL
swf.auth.service.url=http://localhost:8081

# JWT Secret to decode tokens locally inside AVA1 to check roles locally (without making network calls on every request)
jwt.secret=your-256-bit-secret
```

## Step 3: Create Feign Client for Auth Delegation
Create a Feign client interface inside `AVA1` to map exactly to the external endpoints exposed by `SWF-Auth-dev`. 

```java
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;

@FeignClient(name = "swf-auth-service", url = "${swf.auth.service.url}")
public interface SwfAuthClient {
    
    // Delegate Registration directly to external microservice
    @PostMapping("/auth/register")
    AuthResponse registerFallback(@RequestBody RegisterRequest request);

    // Delegate Authentication directly to external microservice
    @PostMapping("/auth/authenticate")
    AuthResponse authenticate(@RequestBody AuthRequest request, @RequestHeader("X-Session-Id") String sessionId);

    // Fetch user details remotely from the service
    @GetMapping("/auth/users/me")
    UserDTO getCurrentUser(@RequestHeader("Authorization") String token);
}
```

Enable Feign Clients in your main application class:
```java
@EnableFeignClients
@SpringBootApplication
public class Ava1Application { ... }
```

## Step 4: Create a Pass-Through Login Controller in AVA1
Create a controller in AVA1 that handles login requests from the frontend and pushes them to SWF Auth via the Feign Client.

```java
@RestController
@RequestMapping("/api/auth")
public class AvaAuthController {

    @Autowired
    private SwfAuthClient swfAuthClient;

    @PostMapping("/login")
    public ResponseEntity<?> login(@RequestBody AuthRequest authRequest, HttpServletRequest request) {
        // Delegate exact credentials to the external Auth Microservice
        String sessionId = request.getHeader("X-Session-Id");
        AuthResponse response = swfAuthClient.authenticate(authRequest, sessionId);
        
        // Pass the token back to the user
        return ResponseEntity.ok(response);
    }
}
```

## Step 5: Implement Local JWT Verification Filter
Because `SWF-Auth-dev` issues standard JWTs signed with a specific secret, `AVA1` doesn't need to ask `SWF-Auth-dev` to validate the token on every single request. It just verifies the signature and decodes the roles.

```java
@Component
public class JwtAuthorizationFilter extends OncePerRequestFilter {
    // Only verify signatures here. Do not generate or encode new tokens!
    
    @Value("${jwt.secret}")
    private String secretKey;

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain filterChain) {
        String authHeader = request.getHeader("Authorization");
        if (authHeader != null && authHeader.startsWith("Bearer ")) {
            String token = authHeader.substring(7);
            try {
                // Decode the external token generated by SWF-Auth-dev
                Claims claims = Jwts.parserBuilder()
                    .setSigningKey(Decoders.BASE64.decode(secretKey))
                    .build()
                    .parseClaimsJws(token)
                    .getBody();
                    
                List<String> roles = claims.get("roles", List.class);
                
                // Set spring security context with the roles from the external token
                List<SimpleGrantedAuthority> authorities = roles.stream()
                    .map(role -> new SimpleGrantedAuthority("ROLE_" + role))
                    .collect(Collectors.toList());
                    
                UsernamePasswordAuthenticationToken authentication = 
                    new UsernamePasswordAuthenticationToken(claims.getSubject(), null, authorities);
                    
                SecurityContextHolder.getContext().setAuthentication(authentication);
            } catch (Exception e) {
                SecurityContextHolder.clearContext();
            }
        }
        filterChain.doFilter(request, response);
    }
}
```

## Step 6: Configure Spring Security
Set up the `SecurityFilterChain` to protect your endpoints and register the `JwtAuthenticationFilter`.

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Autowired
    private JwtAuthenticationFilter jwtAuthenticationFilter;
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(AbstractHttpConfigurer::disable)
            .sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/public/**", "/swagger-ui/**", "/v3/api-docs/**").permitAll() // Adjust based on your API
                .requestMatchers("/admin/**").hasRole("ADMIN_METIER") // Adjust based on required roles
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);
        
        return http.build();
    }
}
```

## Step 7: Accessing User Information in Controllers
You can now access the authenticated user's information and protect methods using `@PreAuthorize`.

```java
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.ResponseEntity;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/ava1")
public class ExampleController {
    
    @Autowired
    private AuthServiceClient authClient;
    
    @GetMapping("/protected-endpoint")
    public ResponseEntity<?> getProtectedData(@RequestHeader("Authorization") String token) {
        // The request has already been authenticated by the JwtAuthenticationFilter
        
        // Fetch detailed user info if needed
        UserDTO user = authClient.getCurrentUser(token);
        
        return ResponseEntity.ok("Hello " + user.getFirstName() + "! You have accessed a protected resource.");
    }
    
    @GetMapping("/admin-only")
    @PreAuthorize("hasRole('ADMIN_METIER')")
    public ResponseEntity<?> adminOnlyData() {
        return ResponseEntity.ok("This data is only available to admins.");
    }
}
```
