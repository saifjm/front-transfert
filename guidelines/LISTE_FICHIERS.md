## 🎯 Actions Recommandées

### Si certains composants ne fonctionnent pas :

Les composants marqués ⚠️ utilisent encore `import { cn } from "./utils"`.
Pour les mettre à jour, changez l'import en :
```typescript
import { cn } from "../../utils";
```

### Commande pour rechercher les imports à corriger :
```bash
grep -r "from \"./utils\"" components/ui/
```

### Script de correction automatique (Linux/Mac) :
```bash
find components/ui -name "*.tsx" -exec sed -i 's/from "\.\/utils"/from "..\/..\/utils"/g' {} \;
```
