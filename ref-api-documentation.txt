# Reference Module API Documentation

## 1. Comptes (Bank Accounts) API
Base URL: `/api/ref/comptes`

### Endpoints:

1. Get All Accounts
   - URL: `/api/ref/comptes/getall`
   - Method: GET
   - Response: List of CompteDTO
   ```json
   [{
     "typePieceClient": 1,
     "noPieceClient": "123456",
     "codeAgenceBct": 1,
     "racineCompte": "12345",
     "cleRib": 12,
     "codeAgenceBna": 1,
     "compteGeneral": 1,
     "sousCompte": 1,
     "cleCompte": "123",
     "codeDevise": 1,
     "compteProfessON": "Y",
     "cptDom": "Y",
     "dateCreation": "2025-11-03",
     "dateCloture": null,
     "etatCompte": "A",
     "sl": 1,
     "sousCompteCplt": 1,
     "categorieProduit": "CAT1",
     "natureCompte": 1
   }]
   ```

2. Get Accounts by Client Document Number
   - URL: `/api/ref/comptes/by-piece-client/{noPieceClient}`
   - Method: GET
   - Path Parameter: noPieceClient (String)
   - Response: List of CompteDTO

3. Get Accounts by Agency
   - URL: `/api/ref/comptes/by-agence/{codeAgenceBct}`
   - Method: GET
   - Path Parameter: codeAgenceBct (Integer)
   - Response: List of CompteDTO

## 2. Payment Modes API
Base URL: `/api/ref/payment-modes`

### Endpoints:

1. Get All Payment Modes
   - URL: `/api/ref/payment-modes`
   - Method: GET
   - Response: List of PaymentModeDTO
   ```json
   [{
     "codeModReg": 1,
     "libModReg": "Payment Mode Label",
     "dom": "Y"
   }]
   ```

## 3. Central Bank Agreements API
Base URL: `/api/ref/central-bank-agreements`

### Endpoints:

1. Get All Agreements
   - URL: `/api/ref/central-bank-agreements/getall`
   - Method: GET
   - Response: AgreementsResponse
   ```json
   {
     "agreements": [{
       "typeAccordBct": 1,
       "numAccordBct": "123",
       "dateAccordBct": "2025-11-03",
       "typePieceClient": 1,
       "noPieceClient": "12345",
       "dateDebApplication": "2025-11-03",
       "dateFinApplication": "2026-11-03",
       "observation": "Note",
       "numContratCom": "COM123",
       "dateContratCom": "2025-11-03",
       "sens": "I",
       "etat": "A"
     }]
   }
   ```

2. Get Agreements by Client Document Number
   - URL: `/api/ref/central-bank-agreements?noPieceClient={noPieceClient}`
   - Method: GET
   - Query Parameter: noPieceClient (String)
   - Response: AgreementsResponse

## Response Data Types:

### CompteDTO
- typePieceClient (Integer): Type of client document
- noPieceClient (String): Client document number
- codeAgenceBct (Integer): Central bank agency code
- racineCompte (String): Account root number
- cleRib (Integer): RIB key
- codeAgenceBna (Integer): BNA agency code
- compteGeneral (Integer): General account number
- sousCompte (Integer): Sub-account number
- cleCompte (String): Account key
- codeDevise (Integer): Currency code
- compteProfessON (String): Professional account indicator
- cptDom (String): Domiciliation account indicator
- dateCreation (Date): Creation date
- dateCloture (Date): Closure date
- etatCompte (String): Account status
- sl (Integer): SL value
- sousCompteCplt (Integer): Complementary sub-account
- categorieProduit (String): Product category
- natureCompte (Integer): Account nature

### PaymentModeDTO
- codeModReg (Integer): Payment mode code
- libModReg (String): Payment mode label
- dom (String): Domiciliation indicator

### CentralBankAgreementDTO
- typeAccordBct (Integer): Agreement type
- numAccordBct (String): Agreement number
- dateAccordBct (Date): Agreement date
- typePieceClient (Integer): Client document type
- noPieceClient (String): Client document number
- dateDebApplication (Date): Start date of application
- dateFinApplication (Date): End date of application
- observation (String): Comments/Notes
- numContratCom (String): Commercial contract number
- dateContratCom (Date): Commercial contract date
- sens (String): Direction indicator
- etat (String): Status

## Common Response Status Codes:
- 200 OK: Successful request
- 404 Not Found: Resource not found
- 400 Bad Request: Invalid parameters
- 500 Internal Server Error: Server error

Note: All dates are in ISO format (YYYY-MM-DD)
