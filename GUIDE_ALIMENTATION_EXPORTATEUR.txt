  📋 PRINCIPE
═══════════════════════════════════════════════════════════════════════════════

Ce module permet de gérer le crédit des dossiers exportateurs en permettant :

  ✓ AUGMENTATION  : Ajouter du crédit au montant autorisé
  ✓ RESTITUTION   : Libérer du crédit utilisé après export

  ⚡ TYPES D'OPÉRATIONS
═══════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────┐
│ 📈 AUGMENTATION                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Objectif   : Augmenter le crédit disponible                                │
│  Action     : Ajoute au montant autorisé                                   │
│  Limite     : Aucune                                                        │
│                                                                             │
│  Exemple :                                                                  │
│  ┌────────────────────────────────────────────────┐                         │
│  │ AVANT             OPÉRATION        APRÈS       │                         │
│  ├────────────────────────────────────────────────┤                         │
│  │ Autorisé: 500k    + 200k     →    Autorisé: 700k │                      │
│  │ Utilisé:  150k      -        →    Utilisé:  150k │                      │
│  │ Solde:    350k      -        →    Solde:    550k │                      │
│  └────────────────────────────────────────────────┘                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│ 📉 RESTITUTION                                                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Objectif   : Libérer du crédit utilisé                                    │
│  Action     : Diminue le montant utilisé                                   │
│  Limite     : Ne peut pas dépasser le montant utilisé                      │
│                                                                             │
│  Exemple :                                                                  │
│  ┌────────────────────────────────────────────────┐                         │
│  │ AVANT             OPÉRATION        APRÈS       │                         │
│  ├────────────────────────────────────────────────┤                         │
│  │ Autorisé: 300k      -        →    Autorisé: 300k │                      │
│  │ Utilisé:  280k    - 100k     →    Utilisé:  180k │                      │
│  │ Solde:     20k      -        →    Solde:    120k │                      │
│  └────────────────────────────────────────────────┘                         │
│                                                                             │
│  ⚠️  VALIDATION : Montant restitution ≤ Montant utilisé                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

CHAMPS OBLIGATOIRES :
  ✓ Type d'opération
  ✓ Montant (> 0)
  ✓ Date opération
  ✓ Référence

RÈGLES SPÉCIFIQUES :

  Pour AUGMENTATION :
    → Pas de limite maximale
    → Montant s'ajoute au montant autorisé

  Pour RESTITUTION :
    → Montant ≤ Montant utilisé
    → Sinon : ❌ "Le montant ne peut pas dépasser le montant utilisé"

═══════════════════════════════════════════════════════════════════════════════
  📊 CALCULS AUTOMATIQUES
═══════════════════════════════════════════════════════════════════════════════

FORMULE GÉNÉRALE :
  Solde = Montant Autorisé - Montant Utilisé


AUGMENTATION :
  Nouveau Montant Autorisé = Ancien Montant Autorisé + Montant Alimentation
  Nouveau Solde = Ancien Solde + Montant Alimentation


RESTITUTION :
  Nouveau Montant Utilisé = Ancien Montant Utilisé - Montant Restitution
  Nouveau Solde = Ancien Solde + Montant Restitution
