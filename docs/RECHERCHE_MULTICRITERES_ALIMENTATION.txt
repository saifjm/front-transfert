  🔍 RECHERCHE MULTICRITÈRES
═══════════════════════════════════════════════════════════════════════════════

Le module de recherche permet de filtrer les dossiers selon 6 critères :

  1. Code Agence        Ex: 001
  2. Agence             Ex: Tunis Centre
  3. Type Dossier       Ex: AVA Import
  4. Numéro Dossier     Ex: EXP-2026-001
  5. N° Pièce Client    Ex: 1234567A
  6. Client             Ex: TUNISIA EXPORT

  🎨 COMPORTEMENT VISUEL
═══════════════════════════════════════════════════════════════════════════════

PANNEAU FILTRES MASQUÉ :
  → Seul le bouton [Afficher les filtres] est visible
  → Gain de place à l'écran
  → Tableau immédiatement visible


PANNEAU FILTRES AFFICHÉ :
  → 6 champs de recherche en grille 3 colonnes
  → Boutons [X Réinitialiser] et [Masquer les filtres]
  → Compteur de résultats en bleu clair


LIGNE SÉLECTIONNÉE :
  → Fond bleu clair (bg-blue-50)
  → Bouton "Sélectionné" en bleu plein
  → Formulaire d'alimentation affiché en dessous


HOVER (survol) :
  → Fond gris léger sur la ligne
  → Transition douce

═══════════════════════════════════════════════════════════════════════════════
  💡 CONSEILS D'UTILISATION
═══════════════════════════════════════════════════════════════════════════════

  📌 Utiliser UN SEUL critère pour commencer
     Ex: Code Agence = 001 → Voir tous les dossiers de cette agence
  
  📌 Ajouter des critères progressivement pour affiner
     Ex: + Type = Import → Voir seulement les imports de cette agence
  
  📌 Utiliser "Numéro Dossier" pour trouver rapidement un dossier précis
     Ex: EXP-2026-001 → Trouve exactement ce dossier
  
  📌 Le bouton "Réinitialiser" n'apparaît que si des filtres sont actifs
     → Économie de place
  
  📌 Les filtres sont persistants jusqu'à réinitialisation
     → Pas besoin de ressaisir à chaque fois
  
  📌 Masquer les filtres après avoir cherché pour voir plus de résultats
     → Gagne de l'espace vertical
