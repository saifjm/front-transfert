  ║ 1️⃣ VALIDATION RNE AUTOMATIQUE (Matricule Fiscal)                        ║
  ╚══════════════════════════════════════════════════════════════════════════╝
  
  ✅ Algorithme BCT (Banque Centrale de Tunisie)
     • Format : 7 chiffres + 1 lettre de contrôle
     • Vecteur de clés : 'ABCDEFGHJKLMNPQRSTVWXYZ' (23 lettres, sans I, O, U)
     • Calcul de la clé : Σ (chiffre × position) % 23
     • Conformité TOTALE avec l'algorithme PL/SQL
  
  ✅ Validation automatique au onBlur
     • Déclenchement lors de la sortie du champ
     • Validation format avant appel API
     • Si invalide → Message d'erreur (pas d'appel API)
     • Si valide → Recherche automatique du client
  
  ✅ Recherche client automatique
     • API : GET /api/ref/clients/search/byPiece
     • Paramètres : typePiece=3, noPiece=RNE
     • Retour : Nom client + liste des comptes
  
  ✅ Indicateurs visuels
     • Spinner pendant recherche
     • Bordure VERTE si client trouvé
     • Bordure ROUGE si erreur format
     • Message VERT : "✓ Client: Jean Dupont"
     • Message ROUGE : "❌ Client non trouvé" ou "❌ Clé de contrôle incorrecte"
  
  ✅ Bouton de recherche manuelle conservé
     • Icône loupe 🔍
     • Validation RNE au clic
     • Spinner intégré
     • Option alternative pour l'utilisateur
