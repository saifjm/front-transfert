│ 2️⃣ VALIDATION AUTOMATIQUE RNE & RECHERCHE CLIENT                            │
└──────────────────────────────────────────────────────────────────────────────┘

  📁 Fichier modifié : /components/AVAForm.tsx
  📄 Documentation : /VALIDATION_RNE_AUTOMATIQUE.txt
  📄 Exemples : /EXEMPLES_CALCUL_RNE.txt
  
  ✅ FONCTIONNALITÉ
  ─────────────────
  
  Le champ "Numéro Pièce Client (RNE)" implémente :
  
  1. Validation automatique du format RNE (algorithme BCT)
  2. Recherche automatique du client lors du onBlur
  3. Indicateurs visuels avancés (spinner, messages colorés, bordures)
  4. Bouton de recherche manuelle conservé
  
  🔐 ALGORITHME RNE (BCT)
  ──────────────────────
  
  Format : 7 chiffres + 1 lettre de contrôle
  Exemple : 1695881M
  
  Validation :
  • Longueur exacte : 8 caractères
  • 7 premiers caractères : chiffres uniquement
  • Valeur < 9999999
  • 8ème caractère : clé calculée selon algorithme BCT
  
  Vecteur de clés : ABCDEFGHJKLMNPQRSTVWXYZ (23 lettres, sans I, O, U)
  
  Formule de la clé :
  Somme = Σ (chiffre[i] × poids[i]) pour i=1..7
  Index = (Somme % 23)
  Clé = Vecteur[Index]
  
  🔧 MODIFICATIONS TECHNIQUES
  ───────────────────────────
  
  ✅ Nouveaux états React
     • rneError: string (message d'erreur format RNE)
     • clientNotFound: boolean (client non trouvé)
  
  ✅ Fonction validateRNE(rne: string)
     • Validation longueur (8 caractères)
     • Validation format (7 chiffres)
     • Validation valeur (< 9999999)
     • Calcul et vérification clé BCT
     • Retourne : { valid: boolean; message: string }
  
  ✅ Fonction handleNoPieceClientBlur()
     • Déclenchée lors du onBlur du champ
     • Valide le format RNE
     • Si valide → lance searchClient() automatiquement
     • Si invalide → affiche message d'erreur
  
  ✅ Fonction searchClient() améliorée
     • Gestion du flag clientNotFound
     • Messages toast améliorés
     • Réinitialisation des états au début
  
  ✅ Interface utilisateur améliorée
     • Conversion automatique en MAJUSCULES
     • maxLength={8}
     • Bordure verte si client trouvé
     • Bordure rouge si erreur RNE
     • Spinner animé pendant recherche
     • Messages contextuels colorés
     • Bouton avec spinner intégré
  
  🎨 INDICATEURS VISUELS
  ──────────────────────
  
  🔵 En cours de recherche
     • Spinner dans bouton
     • Message bleu : "Recherche en cours..."
     • Bouton désactivé
  
  ❌ Erreur format RNE
     • Bordure rouge
     • Message : "Clé de contrôle incorrecte. Attendu: M, trouvé: A"
  
  ❌ Client non trouvé
     • Message rouge : "Client non trouvé pour ce numéro RNE"
     • Toast warning
  
  ✅ Client trouvé
     • Bordure verte
     • Message vert : "✓ Client: Jean Dupont"
     • Liste des comptes affichée dans Select
  
  📊 WORKFLOW AUTOMATIQUE
  ───────────────────────
  
  1. Utilisateur saisit : 1695881M
  2. Utilisateur quitte le champ (Tab ou clic ailleurs)
  3. onBlur déclenché → handleNoPieceClientBlur()
  4. Validation RNE effectuée
     ✓ Format valide
  5. Recherche API lancée automatiquement
     GET /api/ref/clients/search/byPiece?typePiece=3&noPiece=1695881M
  6. Client trouvé
     ✓ Nom affiché en vert
     ✓ Comptes disponibles dans Select
  
  🔍 RECHERCHE MANUELLE
  ─────────────────────
  
  Le bouton 🔍 permet toujours une recherche manuelle :
  
  • Valide le format RNE au clic
  • Lance la recherche même sans onBlur
  • Affiche un spinner pendant la recherche
  • Désactivé si champ vide ou recherche en cours
