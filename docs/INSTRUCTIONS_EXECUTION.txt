🐛 RÉSOLUTION DES PROBLÈMES
================================================================================

PROBLÈME 1 : "Cannot find module 'react'"
SOLUTION :
    rm -rf node_modules package-lock.json
    npm install


PROBLÈME 2 : Port 3000 déjà utilisé
SOLUTION A : Modifier vite.config.ts (ligne 6 : port: 3001)
SOLUTION B (Windows) :
    netstat -ano | findstr :3000
    taskkill /PID <numero_PID> /F
SOLUTION B (Mac/Linux) :
    lsof -ti:3000 | xargs kill -9


PROBLÈME 3 : Page blanche après le lancement
SOLUTION :
    1. Ouvrir la console du navigateur (F12)
    2. Vérifier les erreurs
    3. Relancer : npm run dev


PROBLÈME 4 : Erreur de permissions (EACCES)
SOLUTION (Mac/Linux) :
    sudo npm install


PROBLÈME 5 : Module not found
SOLUTION :
    npm install
    npm run dev
