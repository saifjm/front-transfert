                         📋 LES 13 VALIDATIONS
═══════════════════════════════════════════════════════════════════════════════

  1️⃣  Champs obligatoires (Type dossier, RNE, Compte, Activité, Déclaration)
  2️⃣  Sous-activité (obligatoire pour types 3 et 5 uniquement)
  3️⃣  RNE valide (format 7 chiffres + clé, algorithme BCT)
  4️⃣  Téléphone tunisien (multi-valeurs, séparateur ;)
  5️⃣  Email valide (multi-valeurs, séparateur ;)
  6️⃣  Cohérence BCT (numéro et date ensemble ou aucun)
  7️⃣  Montant importation (conditionnel selon type et activité)
  8️⃣  Montant avance (conditionnel selon type et banque)
  9️⃣  Documents (au moins 1 pièce jointe)
  🔟  Bénéficiaires (au moins 1 bénéficiaire)
  1️⃣1️⃣  Bénéficiaires complets (tous les champs obligatoires)
  1️⃣2️⃣  Date pièce bénéficiaire (≤ date du jour)
  1️⃣3️⃣  Banque provenance (montants complets et formule solde)


═══════════════════════════════════════════════════════════════════════════════
                      🔐 POINTS CLÉS DE SÉCURITÉ
═══════════════════════════════════════════════════════════════════════════════

  ✅  Validation RNE avec algorithme officiel BCT
      → Garantit la conformité réglementaire

  ✅  Arrêt immédiat en cas d'erreur
      → Pas d'appels API inutiles, économie de ressources

  ✅  Conservation des données en cas d'échec
      → L'utilisateur ne perd pas son travail

  ✅  Messages d'erreur détaillés et contextuels
      → L'utilisateur sait exactement quoi corriger

  ✅  Workflow en 2 étapes distinct
      → Séparation création (MVT) vs validation (opération déléguée)

  ✅  Logs complets pour audit et débogage
      → Traçabilité totale de chaque soumission

                         🎯 CODES RETOUR API
═══════════════════════════════════════════════════════════════════════════════

  ÉTAPE 1 : POST /api/operations-deleguees-mvt/initialisation
  ───────────────────────────────────────────────────────────
  
  ✅ 201 Created       → Succès, passage à ÉTAPE 2
  ❌ 400 Bad Request   → Requête invalide, ARRÊT
  ❌ 500 Server Error  → Erreur serveur, ARRÊT

  ÉTAPE 2 : POST /api/operations-deleguees/validation/{numDossier}
  ────────────────────────────────────────────────────────────────
  
  ✅ 201 Created              → Succès complet, modal ouvert
  ❌ 404 Not Found            → Dossier introuvable, ARRÊT
  ❌ 422 Unprocessable Entity → Contrôles métier échoués, ARRÊT
