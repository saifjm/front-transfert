═══════════════════════════════════════════════════════════════════════════════

  1. Ouvrir la console du navigateur (F12)
  2. Naviguer vers le formulaire "Ouverture Dossier AVA"
  3. Avoir un serveur API de test configuré (ou utiliser données mock)

  TEST 1 : VALIDATION RNE - CLÉ DE CONTRÔLE CORRECTE
═══════════════════════════════════════════════════════════════════════════════

  📋 OBJECTIF
  ───────────
  Valider qu'un RNE avec une clé correcte est accepté

  📝 DONNÉES DE TEST
  ──────────────────
  • Numéro RNE : 1695881M

  🔧 PROCÉDURE
  ────────────
  1. Remplir tous les champs obligatoires
  2. Saisir "1695881M" dans "Numéro Pièce Client (RNE)"
  3. Appuyer sur Tab (déclenche la validation onBlur)
  4. Cliquer sur "Soumettre le dossier"

  ✅ RÉSULTAT ATTENDU
  ───────────────────
  • Pas de message d'erreur rouge sur le champ RNE
  • Bordure verte sur le champ (si client trouvé)
  • Le formulaire continue vers les appels API
