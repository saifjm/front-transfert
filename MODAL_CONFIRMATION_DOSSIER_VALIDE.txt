┌──────────────────────────────────────────────────────────────────────────────┐
│ 🎯 OBJECTIF                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  Après la soumission réussie du dossier AVA (validation en 2 étapes), afficher
  toutes les informations du dossier créé dans un popup modal élégant avant de
  permettre à l'utilisateur de réinitialiser le formulaire pour une nouvelle saisie.

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 WORKFLOW MODIFIÉ                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  AVANT (Ancien comportement)
  ────────────────────────────
  
  1. Utilisateur clique "Soumettre le dossier"
  2. Validation côté client
  3. ÉTAPE 1 : POST /initialisation → Succès
  4. ÉTAPE 2 : POST /validation/{numDossier} → Succès
  5. Toast succès "🎉 Dossier AVA créé et validé avec succès !"
  6. Logs console détaillés
  7. ✅ Réinitialisation automatique du formulaire
  
  ─────────────────────────────────────────────────────────────────────────────
  
  MAINTENANT (Nouveau comportement)
  ──────────────────────────────────
  
  1. Utilisateur clique "Soumettre le dossier"
  2. Validation côté client
  3. ÉTAPE 1 : POST /initialisation → Succès
  4. ÉTAPE 2 : POST /validation/{numDossier} → Succès
  5. Toast succès "🎉 Dossier AVA créé et validé avec succès !"
  6. Logs console détaillés
  7. ✅ OUVERTURE DU MODAL avec détails complets du dossier
  8. Utilisateur consulte les informations
  9. Utilisateur clique "Fermer et Nouveau Dossier"
  10. ✅ Réinitialisation du formulaire

  Modal React avec les caractéristiques suivantes :
  • Position : Fixed, centré sur l'écran
  • Overlay : Fond noir semi-transparent (bg-opacity-50)
  • Taille : max-w-5xl, responsive
  • Hauteur max : 90vh avec scroll interne
  • Fermeture : Bouton X + Bouton "Fermer et Nouveau Dossier"
  • Design : Palette IBANSYS (#435B7B, #2D3E54, #D6E4F0)
  
  🎨 SECTIONS DU MODAL
  ────────────────────
  
  1️⃣ Header (Dégradé bleu navy)
     • Icône CheckCircle
     • Titre : "Dossier AVA Créé avec Succès"
     • Sous-titre : "Numéro de dossier : XXXXX"
     • Bouton X pour fermer
  
  2️⃣ Informations Générales (Card avec fond dégradé)
     • Icône Building2
     • Grille responsive (1/2/3 colonnes)
     • Champs affichés :
       - Numéro de dossier
       - Date de création
       - Type de dossier
       - Code agence
       - Type pièce client + label traduit
       - Numéro pièce (RNE)
       - Numéro de compte
       - Téléphone
       - Code activité
       - Code sous-activité (si applicable)
       - Déclaration fiscale
  
  3️⃣ Détails des Montants (Card avec fond dégradé)
     • Icône DollarSign
     • Grille de cards colorées selon le type :
       - Montant Avancé (vert)
       - Montant Autorisé (bleu)
       - Montant Utilisé (violet)
       - Montant Autorisé BCT (orange)
       - Montant Réservé (gris)
       - Montant Blocage (gris)
       - Solde Final (bleu navy, 2 colonnes)
     • Format : X.XXX TND (3 décimales)
  
  4️⃣ Bénéficiaires (Card avec fond dégradé)
     • Icône Users
     • Titre : "Bénéficiaires (N)"
     • Liste de cards pour chaque bénéficiaire
     • Grille 1/2/4 colonnes par bénéficiaire :
       - Nom
       - Type pièce + label traduit
       - N° pièce
       - Qualité
       - Adresse (sur toute la largeur)
     • Hover effect : Shadow
  
  5️⃣ Documents Joints (Card avec fond dégradé)
     • Icône FileText
     • Titre : "Documents Joints (N)"
     • Liste de rows pour chaque document
     • Affichage :
       - Icône FileText dans un badge
       - Nom du fichier
       - Type de document
       - Chemin fichier (tronqué)
     • Hover effect : Background gris clair
  
  6️⃣ Informations du Marché AVA (Card, si applicable)
     • Icône Calendar
     • Grille responsive 1/2/3 colonnes
     • Champs affichés :
       - Numéro de marché
       - Référence contrat
       - Date contrat
       - Contractant
       - Montant marché (TND)
       - Montant devise
       - Code devise
       - Date fin
  
  7️⃣ Footer (Fond gris clair)
     • Bouton "Fermer et Nouveau Dossier"
     • Style : Bleu navy (#435B7B)
     • Hover : Navy dark (#2D3E54)
     • Action : Ferme modal + réinitialise formulaire

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 FONCTIONS UTILITAIRES                                                     │
└──────────────────────────────────────────────────────────────────────────────┘

  formatMontant(montant?: number): string
  ──────────────────────────────────────────
  
  Formate un montant en TND avec 3 décimales
  
  Exemples :
  • formatMontant(10000.5) → "10000.500"
  • formatMontant(1234.567) → "1234.567"
  • formatMontant(undefined) → "0.000"
  • formatMontant(null) → "0.000"
  
  ─────────────────────────────────────────────────────────────────────────────
  
  formatDate(date?: string): string
  ──────────────────────────────────
  
  Formate une date ISO en format français
  
  Exemples :
  • formatDate("2026-02-14") → "14/02/2026"
  • formatDate(undefined) → "N/A"
  • formatDate(null) → "N/A"
  
  ─────────────────────────────────────────────────────────────────────────────
  
  getTypePieceLabel(type?: number): string
  ─────────────────────────────────────────
  
  Traduit le code type de pièce en libellé
  
  Mapping :
  • 1 → "Carte d'Identité Nationale"
  • 3 → "Matricule Fiscal"
  • 4 → "Passeport"
  • 7 → "Autre"
  • Autre → "Non spécifié"

  ──────────────────────────────────────────────────────────
  
  // AVANT
  toast.success('🎉 Dossier AVA créé et validé avec succès !');

  toast.success('🎉 Dossier AVA créé et validé avec succès !');
  setDossierValide(dossierValideResponse); // ✅ Stocker le dossier

    isOpen={showDossierModal}
    dossier={dossierValide}
    onClose={handleCloseModal}
